# Github Introduction

# Pull upgrade

Check the information of the project

```shell
git remote -v
```

Check the local project status

```shell
git status
# nothing to commit, working tree clean
## This mean you can pull the upgrade simply
```

```shell
git pull origin master
```

**But,** if you change some file in your local project, such as config and so on

```shell
git stash #temporary save your change
```

```shell
git pull origin master #pull the project
```

Then, fetch out your saved change file

```shell
git stash pop #
```

If you find some conflict in this pull, you need mannully modify the file, then

```shell
git add config.json
git commit -m 'update'
```
